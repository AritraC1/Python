# Introduction to Machine Learning
Field of study that lets a computer learn without being explicitely programmed.

## Types of ML Algo
- Supervised (Most used in real world applications + rapid advancements)
- Unsupervised
- Recommended Systems
- Re-inforcement learning

## Supervised Learning
Supervised Ml or Supervised Machine Learning refers to algorithms that learn to `x` to `y` or `input` to `output` mappings

#### Key Characteristics
The user gives the system learning algorithm examples to learn from, i.e. It learns from being given the `Right Answers`

```bash
  x   →    y
input →  output
```

#### Examples

| Input          | Output             | Application           |
|----------------|--------------------|-----------------------|
| Email          | Spam? (0, 1)       | Spam Filtering        |
| Audio          | Text transcript    | Speech Recognition    |
| English        | Spanish / French   | Machine Translation   |
| Ad, user, info | Click (0, 1)       | Online Ads            |

#### Types of Supervised Learning
There are 2 types of Supervised Ml:
1. Regression
2. Classification

### Regression
The task of the learning algo is to predict numbers frin infinitely many possible output numbers

### Classification
The learning algo has to make a prediction of a category of a small possible outputs.

## Unsupervised Learning
In this type of machine learning, data inly comes with input x, but not the output labels y, algorithms has to find structure in the labels.

### Clustering (Type of unsupervised learning)
Grouping similar data points together

> Note: 
Anomaly Detection - Findng unusual data points
Dimensionality reduction: Compresses data into fewer numbers
